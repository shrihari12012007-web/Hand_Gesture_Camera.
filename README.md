# Hand Gesture Camera & Desktop Controller

A real-time computer vision human-computer interaction (HCI) system utilizing Python, OpenCV, and Google MediaPipe hand landmark detection to translate physical gestures into fluid desktop and camera control inputs. Featuring sub-millisecond 21-point hand tracking, custom landmark classification, mobile streaming controller integration, and low-latency system-level automation without physical peripheral hardware.
